# Суммаризация научных статей и оценка качества аннотаций
Скрипт для автоматической генерации аннотаций к англоязычным научным статьям с помощью моделей-трансформеров и последующей оценки их качества метриками ROUGE и BERTScore.
Проект выполнен в рамках магистерской диссертации «Оценка качества аннотаций к англоязычным научным статьям, сгенерированных языковыми моделями».

# Что делает скрипт

Загружает модели суммаризации LED и LongT5 из библиотеки transformers.

Читает исходный текст статьи из файла .txt

Очищает текст от «мусорных» ссылок вида (Author, Reference Year).

Токенизирует текст с учётом ограничения длины (до 16384 токенов для LED, до 8192 — для LongT5).

Генерирует аннотацию с настраиваемыми параметрами (num_beams, max_length, repetition_penalty и др.).

Декодирует результат и убирает артефакты (лишние пробелы, строчную букву в начале).

Считает метрики ROUGE-1, ROUGE-2, ROUGE-L и BERTScore (P, R, F1) для сгенерированных аннотаций относительно эталонной (авторской).
